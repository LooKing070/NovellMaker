## Структура конфигурации
```bash
assets/
│
├── fonts/
│   ├── yourFont.otf.ttf
│   └── parameters.json
│
├── scenes/
│   └── your_scene_name/
│       ├── your_object_name/
│       │   ├── events.txt
│       │   ├── parameters.json
│       │   └── speech.txt
│       │
│       ├── parameters.json
│       └── script.txt
│
├── sounds/
│   ├── fon_music/
│   │   └── yourFonMusic.mp3.ogg
│   │
│   └── interaction_sounds/
│       └── yourMusicOrSounds.mp3.ogg
│
├── textures/
│   ├── bg/
│   │   └── yourBackgroundTexture.png.jpg
│   │
│   ├── your_dir/
│   │   └── yourTexture.png.jpg
│   │
│   ├── yourTexture.png.jpg
│   └── NM_icon.png
│
└── videos/
    ├── NMintro.mp4
    └── yourVideo.mp4
```
### Пояснения:
- *Файл/папку с пометкой "_tip" в названии можно удалить без последствий*, это файл примера,
он нужен только для удобства при разработке собственной конфигурации.
- Файлы *NMintro и NM_icon нельзя удалять*, без них проект не запустится.
